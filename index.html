Corn Yield Predictor

An interactive decision-support tool that estimates corn yield in bushels per acre from season inputs and weekly rainfall, and warns about rainfall stress.

  • Weights growing degree days, rainfall, nitrogen, fertilizer, and pesticide into a yield index.
  • Flags pollination stress and multiple dry weeks, then reduces the prediction accordingly.
  • Uses a custom-styled form with clear focus states.

  • CSS
  • JavaScript

Soccer Tournament Results

A results page that turns raw team data into a points summary, goal differences, win percentages, and a star-based bar chart.

  • Stores wins, ties, losses, and goals in arrays and calculates every table from them.
  • Checks that each team's game count adds up before showing results.
  • Draws the bar chart with nested loops.
